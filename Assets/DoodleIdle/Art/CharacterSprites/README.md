PSB/에는 캐릭터 142종의 파츠별 레이어 PSB가 있습니다. 레이어 이름은 머리·몸통·팔1·팔2·다리1·다리2 등의 타입별 이름으로 통일했습니다. 같은 타입의 레이어 원점과 영역은 동일합니다. 몸통·팔다리는 공통 영역에 맞추고, 적·동료 머리는 비율을 유지하여 하단 중앙에 정렬했습니다. 날개와 꼬리는 부위별 공통 뿌리·끝점·폭에 맞춰 정렬했습니다. 플레이어 머리는 모자 외곽이 아닌 두 눈과 얼굴 아래쪽 기준점으로 정렬했습니다.
