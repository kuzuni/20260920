# 파츠별 레이어 PSB

플레이어 41종 (기본형 1종 + 테마 40종), 적 69종, 동료 32종을 각각 독립된 PSB로 저장했습니다. 상위 PNG 폴더 구조와 파일 이름을 그대로 사용합니다. 문서 크기는 1500×1700이며 부위를 타입별 공통 좌표에 맞춰 이동·크기 조정했습니다.

## 레이어 이름 (Photoshop 패널 위에서 아래 순서)

| 타입 | 수량 | 레이어 |
|---|---:|---|
| 일반 2족형 | 71 | 머리, 몸통, 팔1, 팔2, 다리1, 다리2 |
| 몸통 있는 날개형 | 4 | 머리, 몸통, 날개1, 날개2, 다리1, 다리2 |
| 머리·두발형 | 28 | 머리, 다리1, 다리2 |
| 머리·날개형 | 27 | 머리, 날개1, 날개2 |
| 4족형 | 12 | 머리, 몸통, 다리1, 다리2, 다리3, 다리4, 꼬리 |

팔·다리 번호는 원본 시트에서 왼쪽부터입니다. 날개 두 개가 좌우로 배치된 경우 왼쪽부터, 위아래로 배치된 경우 위쪽부터 1·2입니다. 4족형은 다리1·2가 뒷다리, 다리3·4가 앞다리입니다. 모자와 머리에 붙어 있는 장식은 머리 레이어에 포함합니다. 별도 플레이어 무기는 상위 Player/Weapons의 PNG를 사용합니다.

배경 레이어, 병합 복제 레이어, 불필요한 그룹을 추가하지 않았습니다. 부위별 레이어는 투명 여백을 포함한 타입별 고정 사각형으로 저장하여 원점과 크기를 동일하게 유지합니다. 모자 크기가 달라도 머리 레이어 원점은 같습니다. 한글 유니코드 이름과 파일 내 고유 레이어 ID를 기록했습니다.

## 타입별 폴더

Enemies는 일반2족형(30), 몸통있는날개형(4), 머리두발형(12), 머리날개형(11), 4족형(12)으로 나눴습니다. Companions는 머리두발형(16, 낮은 등급), 머리날개형(16, 높은 등급)으로 나눴습니다. 동일 이름의 PNG도 상위 폴더에서 같은 분류로 찾을 수 있습니다.

## 검증

2026-09-28: 전체 142개를 PSB 형식 버전 2, RLE 압축으로 저장했습니다. 이전 117종은 Photoshop 2026에서 열기 검증을 통과했으나 이는 정렬 전 기록입니다. 이번 정렬본의 Photoshop 앱 재검사는 화면 제어 오류로 수행하지 못했습니다. 현재 상태는 photoshop_validation.txt에 명시했습니다.

파일을 다시 열어 문서 크기, 레이어 이름·개수, 공통 원점·영역, 알파, 부위별 픽셀 복원을 검사했습니다. 전체 레이어 재합성 결과의 보이는 RGBA 픽셀과 알파는 현재 PNG와 정확히 일치합니다. 개별 검증 결과와 좌표는 layer_manifest.json 및 rig_alignment_report.json에 있습니다. 플레이어 눈 기준점의 측정 오차는 최대 0.5px입니다.

같은 타입끼리 부위 배치와 레이어 영역을 통일한 결과입니다. 머리·꼬리 외형은 디자인별로 다릅니다. Unity 메타에 타입별 공통 본과 개별 메시·가중치를 저장했습니다. 타입별 본 이름·GUID·부모·위치·회전·길이가 같은지 다시 읽어 대조했습니다.

기존 이미지 메타는 프로젝트 밖에 백업하고 Unity에서 재생성했습니다. 본과 메시를 보존하도록 Reslice From Layer는 꺼 두었습니다. Unity는 투명 여백을 잘라 스프라이트를 패킹하므로 개별 스프라이트의 로컬 사각형과 로컬 본 좌표는 디자인별로 다를 수 있습니다. 공통 본은 캐릭터 문서 좌표 기준입니다. 실제 프리팹은 ../../../CharacterRigs/Prefabs에 있습니다.

Player/Characters/00_default.psb는 누락 보완한 기본형입니다. 전체 PSB는 142개이며, 기본형도 머리·몸통·팔1·팔2·다리1·다리2로 분리했습니다.

## 플레이어 공통 두개골 수정

플레이어 41종의 머리는 00_default.psb의 머리 원본을 공통으로 사용합니다. 이전의 눈 기준점 정렬만으로 남아 있던 볼·턱·두개골 형태 차이를 수정했습니다. 테마 모자는 공통 머리 위에 맞추고 최종 머리 레이어로 합쳤습니다. 이번 수정에서 40개 테마의 모자를 내장 imagegen으로 다시 생성하고 공통 머리 위에 맞췄습니다. 교복 테마는 화가(01_painter)로 바꿨습니다.

41종 전부 같은 머리 원본 해시를 사용했는지, 얼굴 중심 영역과 하단 두개골 픽셀이 동일한지, 공통 레이어 원점·크기를 유지하는지, PSB 재합성이 PNG와 일치하는지 검사했습니다. shared_player_head_report.json에 기록했습니다. 모자에 가려지는 피부 영역은 디자인에 따라 다릅니다. 현재 파일의 Photoshop 앱 재열기는 별도로 수행하지 않았습니다. Unity에서는 전체 142종을 가져와 공통 본·개별 메시·외형 교체를 검사했습니다. 자세한 결과는 ../../../CharacterRigs/Reports에 있습니다.
