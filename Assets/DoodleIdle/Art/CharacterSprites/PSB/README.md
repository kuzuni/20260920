# 파츠별 레이어 PSB

플레이어 40종, 적 45종, 동료 32종을 각각 독립된 PSB로 저장했습니다. 상위 PNG 폴더 구조와 파일 이름을 그대로 사용합니다. 문서 크기는 원본과 같은 1500×1700이며 부위를 이동하거나 확대·축소하지 않았습니다.

## 레이어 이름 (Photoshop 패널 위에서 아래 순서)

| 타입 | 수량 | 레이어 |
|---|---:|---|
| 일반 2족형 | 70 | 머리, 몸통, 팔1, 팔2, 다리1, 다리2 |
| 몸통 있는 날개형 | 4 | 머리, 몸통, 날개1, 날개2, 다리1, 다리2 |
| 머리·두발형 | 20 | 머리, 다리1, 다리2 |
| 머리·날개형 | 19 | 머리, 날개1, 날개2 |
| 4족형 | 4 | 머리, 몸통, 다리1, 다리2, 다리3, 다리4, 꼬리 |

팔·다리 번호는 원본 시트에서 왼쪽부터입니다. 날개 두 개가 좌우로 배치된 경우 왼쪽부터, 위아래로 배치된 경우 위쪽부터 1·2입니다. 4족형은 다리1·2가 뒷다리, 다리3·4가 앞다리입니다. 모자와 머리에 붙어 있는 장식은 머리 레이어에 포함합니다. 별도 플레이어 무기는 상위 Player/Weapons의 PNG를 사용합니다.

배경 레이어, 병합 복제 레이어, 불필요한 그룹을 추가하지 않았습니다. 부위별 레이어는 그림의 경계까지만 저장하되 원래 캔버스 좌표 오프셋을 보존합니다. 한글 유니코드 이름과 파일 내 고유 레이어 ID를 기록했습니다.

## 검증

2026-09-28: ZIP 압축 저장본에서 발생한 Photoshop 열기 오류를 수정하고 전체 117개를 RLE로 다시 저장했습니다. Photoshop 2026 (27.10.0)에서 117개 전부 실제 열기, 문서 크기, 한글 레이어 이름·개수 검사를 통과했습니다. 기록은 photoshop_validation.txt에 있습니다.

PSB 형식 버전 2로 저장 후 다시 열어 문서 크기, 레이어 이름·개수, 알파, 부위별 픽셀 복원을 검사했습니다. 모든 레이어를 원래 좌표에 겹쳐 놓은 결과의 보이는 RGBA 픽셀과 알파는 원본 PNG와 정확히 일치합니다. 개별 검증 결과와 좌표는 layer_manifest.json에 있습니다.

이는 원본 PNG를 레이어로 분리한 결과이며, 서로 다른 캐릭터 간 관절 좌표를 새로 정렬한 작업은 아닙니다. 본·메시·스킨 가중치는 포함하지 않으며 Photoshop/Unity 앱에서의 실제 리깅 동작은 검증하지 않았습니다.
