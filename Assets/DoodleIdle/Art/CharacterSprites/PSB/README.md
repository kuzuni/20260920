# 파츠별 레이어 PSB

플레이어 41종 (기본형 1종 + 테마 40종), 적 45종, 동료 32종을 각각 독립된 PSB로 저장했습니다. 상위 PNG 폴더 구조와 파일 이름을 그대로 사용합니다. 문서 크기는 1500×1700이며 부위를 타입별 공통 좌표에 맞춰 이동·크기 조정했습니다.

## 레이어 이름 (Photoshop 패널 위에서 아래 순서)

| 타입 | 수량 | 레이어 |
|---|---:|---|
| 일반 2족형 | 71 | 머리, 몸통, 팔1, 팔2, 다리1, 다리2 |
| 몸통 있는 날개형 | 4 | 머리, 몸통, 날개1, 날개2, 다리1, 다리2 |
| 머리·두발형 | 20 | 머리, 다리1, 다리2 |
| 머리·날개형 | 19 | 머리, 날개1, 날개2 |
| 4족형 | 4 | 머리, 몸통, 다리1, 다리2, 다리3, 다리4, 꼬리 |

팔·다리 번호는 원본 시트에서 왼쪽부터입니다. 날개 두 개가 좌우로 배치된 경우 왼쪽부터, 위아래로 배치된 경우 위쪽부터 1·2입니다. 4족형은 다리1·2가 뒷다리, 다리3·4가 앞다리입니다. 모자와 머리에 붙어 있는 장식은 머리 레이어에 포함합니다. 별도 플레이어 무기는 상위 Player/Weapons의 PNG를 사용합니다.

배경 레이어, 병합 복제 레이어, 불필요한 그룹을 추가하지 않았습니다. 부위별 레이어는 투명 여백을 포함한 타입별 고정 사각형으로 저장하여 원점과 크기를 동일하게 유지합니다. 모자 크기가 달라도 머리 레이어 원점은 같습니다. 한글 유니코드 이름과 파일 내 고유 레이어 ID를 기록했습니다.

## 타입별 폴더

Enemies는 일반2족형(30), 몸통있는날개형(4), 머리두발형(4), 머리날개형(3), 4족형(4)으로 나눴습니다. Companions는 머리두발형(16, 낮은 등급), 머리날개형(16, 높은 등급)으로 나눴습니다. 동일 이름의 PNG도 상위 폴더에서 같은 분류로 찾을 수 있습니다.

## 검증

2026-09-28: 전체 118개를 PSB 형식 버전 2, RLE 압축으로 저장했습니다. 이전 117종은 Photoshop 2026에서 열기 검증을 통과했으나 이는 정렬 전 기록입니다. 이번 정렬본의 Photoshop 앱 재검사는 화면 제어 오류로 수행하지 못했습니다. 현재 상태는 photoshop_validation.txt에 명시했습니다.

파일을 다시 열어 문서 크기, 레이어 이름·개수, 공통 원점·영역, 알파, 부위별 픽셀 복원을 검사했습니다. 전체 레이어 재합성 결과의 보이는 RGBA 픽셀과 알파는 현재 PNG와 정확히 일치합니다. 개별 검증 결과와 좌표는 layer_manifest.json 및 rig_alignment_report.json에 있습니다. 플레이어 눈 기준점의 측정 오차는 최대 0.5px입니다.

같은 타입끼리 부위 배치와 레이어 영역을 통일한 결과입니다. 머리·꼬리 외형은 디자인별로 다릅니다. 본·메시·스킨 가중치는 포함하지 않으며 Unity에서 실제 본 복사와 변형 동작은 검증하지 않았습니다.

Unity의 기존 스프라이트 영역이 남지 않도록 PSB importer의 resliceFromLayer를 활성화했습니다. 다음 가져오기에서 수정된 영역을 사용합니다. Unity는 투명 여백을 잘라 스프라이트를 패킹하므로 개별 스프라이트의 로컬 사각형은 디자인별로 다를 수 있습니다. 본 복사 시 캐릭터 문서 좌표를 기준으로 확인하세요. 수동 슬라이스를 편집할 때는 Reslice 옵션을 끄세요. Unity 새로고침은 MCP 연결 오류로 검증하지 못했습니다.

Player/Characters/00_default.psb는 누락 보완한 기본형입니다. 전체 PSB는 118개이며, 기본형도 머리·몸통·팔1·팔2·다리1·다리2로 분리했습니다.
