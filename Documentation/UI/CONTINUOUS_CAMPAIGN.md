# 새 계정 연속 성장 측정

목표는 8시간 플레이로 300스테이지를 클리어하는 것이다. 계수는 실제 연속 측정 결과에 맞춰 조정하며 세부 수치는 `DAY_ONE_BALANCE.md`에 기록한다.

`ContinuousFirstDayCampaignReachesStage300`은 기존 구간별 전투 검사와 달리 골드·다이아·스탯 레벨·보유 아이템 0에서 시작한다. 스테이지나 인벤토리를 중간에 주입하지 않는다. GitHub Actions의 `campaign`(전체 회귀 포함) 또는 `campaign-only`(관련 전투 검사 포함) 범위에서 실행하는 긴 검사이며 일반 테스트 실행에서는 제외한다.

## 플레이 규칙

- 기본 자동 전투와 실제 장착 스킬·동료를 사용한다. 물리 연산 간격은 그대로 두고 Unity 시간 배율만 64배로 설정한다. 보고 시간은 배율을 적용한 게임의 물리 시간이다.
- 기본 공격 탄환·돌의 이동/피해 판정과 전투 경과 시간도 `FixedUpdate`에서 처리한다. 렌더 프레임이 길어졌을 때 탄환 수명을 초과해 이동하던 오차를 없앴다. 시각 효과와 카메라 보간은 별도로 렌더 프레임에서 갱신한다.
- 출석 1회, 무료 다이아 30회, 각 종류 무료 5회 뽑기 3회, 룰렛 5회를 실제 지급 함수로 받는다. 유료 결제나 마일리지 지급은 없다.
- 30초마다 완료된 퀘스트·메인 미션 수령, 보유 티켓 뽑기, 강화, 자동 장착을 실행한다. 스탯 네 종류는 가장 낮은 레벨부터 보유 골드로만 구매한다.
- 유물 강화는 실제 50% 성공 판정을 사용한다. 뽑기·유물·룰렛 난수 시드는 기록된 값으로 고정하며 원하는 아이템을 직접 지급하지 않는다.
- 여유 다이아는 네 종류(갑옷·몽둥이·스킬·동료) 중 누적 뽑기 횟수가 가장 적은 종류에 10회씩 사용하고 버프용 500다이아를 남긴다.
- 버프는 가속된 게임 시간 기준 15분에 만료된다. 만료 후 실제 가격을 지급하고 재활성화한다. UTC 기반 서비스의 버프 만료 시간만 테스트 안에서 가속 시간에 대응시킨다.
- 해당 던전의 권장 난이도에 도달하면 골드·유물 동굴을 실제로 입장한다. 실패해도 시도 횟수는 복구하지 않는다. 던전 전투와 사망 강등 시간도 포함한다.
- 계정의 일일 허용량은 한 번만 이용한다. 달력 날짜가 바뀌면서 생기는 추가 무료 보상은 측정 범위가 아니다.
- UI 조작은 자동화하므로 사람의 클릭·판단 지연은 재현하지 않는다. 전투를 계속 켜고 30초 간격으로 관리하는 플레이 기준이며 모든 사람의 평균 도달 시간을 뜻하지 않는다.

## 결과 파일

Actions 아티팩트의 `campaign.csv`에는 시간, 현재/최고 스테이지, 메인 스테이지 강등 횟수(`deaths` 열), 네 스탯 레벨, 공격력, 잔여 재화, 미션 번호, 던전 클리어 단계를 기록한다. 강등 횟수에는 단계가 낮아지지 않는 1스테이지 사망이나 던전 실패가 포함되지 않지만, 그때 소비한 시간과 재화는 측정에 포함된다. `playmode.log`에는 최종 보유/장착 목록도 남긴다. 300 클리어 또는 게임 시간 12시간에 종료한다.

`BalanceRuns/eight-hour-baseline.csv`는 물리 시간 통일 전의 잠정 측정 기록이다(5시간 3분 57초). 당시 배속 실행의 기본 공격 범위 오차가 포함되므로 최종 도달 시간의 근거로 사용하지 않는다.

`BalanceRuns/fixed-clock-ratio10.csv`는 물리 시간 통일 후 적 체력 계수 10의 측정 기록이다. 300 클리어까지 4시간 36분 11초, 스탯 Lv.1235, 공격력 약 1.25c를 기록했다. 이를 기준으로 성장 수급은 유지하고 적 체력 계수를 조정한다.

`BalanceRuns/fixed-clock-ratio18.csv`는 적 체력 계수 18의 후속 기록이다. 300 클리어까지 7시간 8분 5초, 스탯 Lv.1234~1235, 공격력 약 1.26c였다. 두 측정의 시간 차이를 사용해 8시간에 가까운 다음 계수를 정하고, 최종 도달 시간은 다시 연속 플레이로 검증한다.

최종 `BalanceRuns/eight-hour-final.csv`는 적 체력 계수 20.75의 기록이다. [실행 35795466557](https://github.com/kuzuni/20260920/actions/runs/35795466557)에서 300 클리어까지 **7시간 59분 27초**, 네 스탯 Lv.1234, 공격력 약 1.25c, x2 치명타 30.85%를 기록했다. 연속 성장과 관련 전투 검사 5개가 모두 통과했다. 이 값은 향후 수동 튜닝과 보급량 조정의 기준으로 남긴다.
