# 최종 시안 레이아웃 기준

`FinalDesign` 25장 원본을 사용한다. 원본마다 해상도가 다르므로 가로 720 기준으로 환산하고 종횡비를 유지해 비교한다. 화면을 같은 사각형으로 늘린 연락 시트는 치수 측정에 사용하지 않는다. 기존 전투 월드와 예시 수치 대신 UI의 크기·위치·정보 순서·여백을 비교한다.

## 세로 화면의 패널 목표

| 화면 | 폭 × 높이 (논리 단위) | 위에서 잰 중심 비율 |
|---|---:|---:|
| 스탯 | 576 × 1010 (최신 요청의 5개 행) | 44.2% |
| 장비 | 568 × 856 | 48.0% |
| 스킬 | 552 × 1008 | 51.5% |
| 동료 | 582 × 866 | 49.4% |
| 유물 | 568 × 880 | 48.4% |
| 던전 | 588 × 820 | 48.0% |
| PVP | 574 × 925 | 47.0% |
| 상점 뽑기 / 재화 | 570 × 1010 / 880 | 49.0% |
| 확률 안내 | 570 × 1110 | 52.0% |
| 출석 / 룰렛 | 576 × 865 | 49.0% |
| 버프 | 558 × 860 | 49.0% |
| 퀘스트 | 574 × 835 | 49.0% |
| 설정 | 510 × 750 | 49.3% |
| 아이템 상세 | 360 × 550 | 64.5%, 안전 영역 제한 |
| 스킨 | 570 × 1000 | 48.0%, 장비 계열 |

전체 Canvas는 Scale With Screen Size / Match Width Or Height / Match=1(Height), 기준 해상도720×1520(9:19)이다. 모든 비율에서 화면 높이에 따라 HUD·패널·아이콘·슬롯·글자·하단 메뉴가 함께 확대/축소된다. UI의 기준 폭720은 가운데 유지해 가로 화면에서 배치가 벌어지지 않게 한다. 게임 화면과 dim/전체 화면 배경은 화면 전체를 사용한다.

팝업 전용 축소 부모는 사용하지 않는다. 패널 치수, 제목, 아이콘, 슬롯, 여백, 스크롤 및 고정 하단 버튼은 기준 화면과 동일하다. 전체 화면 채팅·뽑기 결과도 실제 내용은 기준 폭720에 배치한다. DOTween은 같은 Canvas 배율 안에서 팝업과 버튼을 애니메이션한다.

## 구성 보정

- 01: 큰 프로필/재화, 원형 버프와 상태점, 왼쪽 활동 5개, 큰 우하단 미션, 8개 원형 쿨타임, 구분선이 있는 하나의 하단 메뉴 프레임. 선택한 메뉴는 빨간 X로 표시한다.
- 02–05, 19–21: 큰 스탯 아이콘과 골드 가격 버튼, 장비 정보의 효과 배지, 목록의 밝은 등급 테두리/원형 장착 체크/자물쇠, 보유 효과 띠, 고정 액션과 장비 탭, 작은 상세창의 별도 효과 블록.
- 06–07: 왼쪽 던전 삽화/오른쪽 입장 정보, 캐릭터가 단상 위에 올라간 순위 3명과 아래 순위 목록.
- 08–10, 22–23: 고정 상점 탭, 더 촘촘한 가로 상품 행, 큰 결과 배너와 세로 카드, 하단 뽑기 진행/버튼, 등급별 확률과 아이템 목록.
- 11–18: 세로 출석 카드와 상태띠, 큰 원형 룰렛, 아이콘 옆 버프 정보, 퀘스트 진행 카운터, 양쪽 채팅 말풍선, 아이콘과 토글/슬라이더가 있는 설정.
- 24–25: 큰 패널 없이 제목·개별 세로 보상 카드·노란 후광·닫기 안내.

## 최신 후속 규칙

- 원본의 장비 탭처럼 회색/노란색 두 탭을 이어 붙이며, 같은 구조를 스킨 무기/외형 탭에도 사용한다. 스킨 상세의 미획득 상태는 구매 또는 조건 달성 후 해방 버튼을 표시한다.
- 메인 미션 카드에 500다이아 수령 버튼을 넣기 위해 높이를 184로 확장한다. 스킬 표시 위 왼쪽에 카메라 1/2/3 전환 버튼, 그 위에 실제 스테이지 진행을 표시한다.
- 왼쪽 활동 버튼, 카메라와 스테이지 표시도9:19의 치수·간격·위치를 유지하며 Canvas와 함께 축소한다. 스킨의 긴 상세/목록은 스크롤하며 선택 시 상세 상단으로 이동한다.
- 최신 기능에 따라 스탯은 5개 행과 ×1/×10/×100/MAX, 유물은 5개 행과 유물 수량/고정50%를 표시한다. 원본 예시 수치·행 수보다 사용자의 최신 명시 규칙을 우선한다.

- 장비·스킬·동료의 선택/장착/보유 슬롯과 뽑기 결과는 공통 가로:세로 3:4를 유지한다. 팝업은 화면 비율에 따라 열 수나 여백을 바꾸지 않고 9:19 기준을 유지한다. 슬롯 내부 등급·그림·수량·체크·잠금 표시도 팝업과 함께 축소된다.
- 재화 상품은 단일 다이아/다이아 묶음/주머니/갈색 상자/보라색 상자 5종의 손그림을 각각 사용한다. 시안처럼 크림색 행 왼쪽에는 그림·수량, 오른쪽에는 파란 원화 가격 버튼을 배치한다.
- 유료 10회/50회 뽑기 버튼 안에는 제목 아래 다이아 아이콘과 비용을 둔다. 무료 버튼에는 비용을 넣지 않는다.
- 결과 화면은 아이보리 바탕, 플레이어 문장, 양 끝이 접힌 노란 리본, 색종이·강조선, 등급 카드, 레벨·경험치·게이지·재뽑기·확인 순서로 구성한다. 모든 비율에서 같은 세로 배치를 사용하며 50회 결과는 스크롤한다.
- 게임 재화·전투력·피해량·스탯·수량은 1,000마다 a/b/c/d…를 붙인다(1a=1,000, 1b=1,000,000). 소수 한 자리 반올림, 불필요한 0 생략, z 다음 aa. 저장/계산값은 유지하며 원화 가격·시간·확률은 원래 단위를 사용한다.

## 검증

원격 PlayMode의 31개 상태와 추가 목록 하단/복수 보상을 5비율로 캡처하고 기존 기능/입력 테스트와 함께 확인한다. 720×1520에서는 시안에서 측정한 주요 패널 폭·높이·위치와 HUD 비율을 별도로 검사한다. 다른 비율에서는 9:19 캡처의 팝업·아이콘·제목·본문·하단 버튼 치수와 배치가 유지되는지 비교한다. 이 검사는 전체 시안과의 픽셀 동일성을 보장하지 않으며, 실제 캡처를 직접 여는 시각 검토도 수행한다. 최신 결과와 미완료 항목은 `PROGRESS.md`에 기록한다.
