# 동료·스킬·접촉 피해 수정

꿀벌/꿀 탄환/번개 2컷/날씬한 가지/골렘 내려찍기 이미지는 내장 image_gen으로 생성했다. [정확한 프롬프트와 저장 경로](companion-skill-polish-art-prompts.json)에 모든 요청을 기록했다. 새 PNG의 알파를 그대로 보존하며 기존 임포터 메타 변경은 포함하지 않는다.

동료 원본 6개 아틀라스의 B행은 A행보다 몸통이 높았다. 눈의 위치를 기준으로 각 프레임의 피벗 bodyOffsetY를 보정했다. 이미지 픽셀/눈/날개 모양은 수정하지 않는다. 몸통 위치와 그림자는 고정되고 2컷 날개/발 모션은 계속 재생된다. 꿀벌은 새 2컷 리소스와 꿀방울을 사용하며 저장 ID companion_cloud_friend는 유지한다.

동료 탄환 8개 복제본을 터뜨리던 CompanionBurst 시각 오브젝트를 없앴다. 기존 범위 피해와 등급별 공격 패턴은 유지한다. 비교 시트 오른쪽은 테스트 전용으로 재현한 **제거 전 연출**이며 게임에서 실행되지 않는다.

번개는 0.3초 동안 0.15초씩 2컷 표시하며 기존 3명 피해를 중복 적용하지 않는다. 토네이도 그림자는 발밑을 따라간다. 메테오는 0/1/2초에 낙하를 시작하며 자동 발동 도중 해제하면 아직 발사하지 않은 메테오를 취소한다. 이미 떨어지는 운석과 디버그 발동은 유지한다.

보라 불화살은 최초 발사 방향으로 초당 12 유닛, 최대 2.5초 전진한다. 좌우 진폭은 0.2 유닛이다. 매 이동 구간과 적 원형 판정의 교차를 검사하며 화살마다 적을 1번씩 타격한다. 추적/재타겟/명중 후 소멸은 적용하지 않는다. 8연발, 44/128 계수 피해, 치명타와 스킬 유물, 불꽃/잔상을 유지한다.

골렘은 0.2초 준비 후 0.18초 내려찍기 컷을 유지한다. 실제 타격과 22개 먼지 입자 방출은 준비에서 내려찍기로 전환할 때 일어난다. 0.65초 공격 주기/5마리/10초 지속/기존 단일 타격 피해를 유지한다. 먼지의 원형 확산은 시각 효과이며 추가 피해를 중복시키지 않는다.

접촉 피해는 모든 살아 있는 적의 콜라이더 반지름과 월드 스케일을 반영한다. 플레이어/적의 상대 이동 구간도 검사하여 빠른 돌진 접촉을 놓치지 않는다. 기본 피해는 Inspector의 enemyContactDamage=64, 공통 무적은 1초이며 0.1초마다 검정(알파 0.48)/원래색(알파 0.7)으로 교대한다. 일시정지에서는 타이머가 진행되지 않는다. 스탯/갑옷/유물의 최대 체력과 초당 회복을 사용하고 피해를 입었을 때 플레이어 HP바를 표시한다. 체력이 소진되면 같은 스테이지 중앙에서 체력을 회복하고 1초 보호를 이어간다. 재화나 스테이지는 차감하지 않는다.

검증은 GitHub Actions PlayMode에서 수행하며 탄환 비교 3장, 골렘 먼지, 접촉 무적 두 색, 번개 두 컷, 메테오, 스킬 5열 화면을 출력한다.
