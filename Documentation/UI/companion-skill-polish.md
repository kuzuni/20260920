# 동료·스킬·접촉 피해 수정

## 동료 폭발 개별 입자 교체 후속

폭발형 동료 16종은 효과 삭제 상태에서 개별 파편 ParticleSystem으로 교체했다. `CompanionImpacts.png`의 4×4 각 칸은 완성된 폭발이 아니라 잎 하나/물방울 하나/꿀방울 하나/금속 조각 하나/얼음 조각 하나/빛 조각 하나/불티 하나다. [내장 image_gen 최종 프롬프트와 저장 경로](companion-impact-particle-prompt.json).

명중 시 10~15개의 작은 입자를 서로 다른 방사 속도와 수명으로 발사한다. 스나이퍼는 5개의 작고 짧은 스파크만 낸다. 물·꿀은 중력으로 아래로 떨어지고, 잎·금속·가시·얼음은 회전하며 떨어지고, 불티는 살짝 떠오른다. 입자는 작아지며 사라지고 이미 발사된 탄환 그림을 복제하지 않는다. 기존 범위 피해/발사 수/발사 간격은 그대로다. 16개의 효과별 재사용 풀을 기존 고정 시간 시뮬레이션·일시정지·초기화 경로에 연결했다.

서버 검사는 16종 모두 개별 입자 수·작은 크기·속도·위치 이동·소멸·초기화를 확인하고 실제 ParticleSystem을 0.04/0.11/0.25초에 캡처한다. 비교표는 `companion-impact-before-after-1.png`~`3.png`이며 **이전 탄환 복제 효과 / 입자 한 개 / 실제 새 효과** 순서다. 원래 폭발이 없는 8종은 변경하지 않는다.

이하 최초 반영 기록의 '폭발 시각 효과 제거'는 위 개별 입자 효과로 대체되었다.

꿀벌/꿀 탄환/번개 2컷/날씬한 가지/골렘 내려찍기 이미지는 내장 image_gen으로 생성했다. [정확한 프롬프트와 저장 경로](companion-skill-polish-art-prompts.json)에 모든 요청을 기록했다. 새 PNG의 알파를 그대로 보존하며 기존 임포터 메타 변경은 포함하지 않는다.

동료 원본 6개 아틀라스의 B행은 A행보다 몸통이 높았다. 눈의 위치를 기준으로 각 프레임의 피벗 bodyOffsetY를 보정했다. 이미지 픽셀/눈/날개 모양은 수정하지 않는다. 몸통 위치와 그림자는 고정되고 2컷 날개/발 모션은 계속 재생된다. 꿀벌은 새 2컷 리소스와 꿀방울을 사용하며 저장 ID companion_cloud_friend는 유지한다.

동료 탄환 8개 복제본을 터뜨리던 CompanionBurst 시각 오브젝트를 없앴다. 기존 범위 피해와 등급별 공격 패턴은 유지한다. 비교 시트 오른쪽은 테스트 전용으로 재현한 **제거 전 연출**이며 게임에서 실행되지 않는다.

번개는 0.3초 동안 0.15초씩 2컷 표시하며 기존 3명 피해를 중복 적용하지 않는다. 토네이도 그림자는 발밑을 따라간다. 메테오는 0/1/2초에 낙하를 시작하며 자동 발동 도중 해제하면 아직 발사하지 않은 메테오를 취소한다. 이미 떨어지는 운석과 디버그 발동은 유지한다.

보라 불화살은 최초 발사 방향으로 초당 12 유닛, 최대 2.5초 전진한다. 좌우 진폭은 0.2 유닛이다. 매 이동 구간과 적 원형 판정의 교차를 검사하며 화살마다 적을 1번씩 타격한다. 추적/재타겟/명중 후 소멸은 적용하지 않는다. 8연발, 44/128 계수 피해, 치명타와 스킬 유물, 불꽃/잔상을 유지한다.

골렘은 0.2초 준비 후 0.18초 내려찍기 컷을 유지한다. 실제 타격과 22개 먼지 입자 방출은 준비에서 내려찍기로 전환할 때 일어난다. 0.65초 공격 주기/5마리/10초 지속/기존 단일 타격 피해를 유지한다. 먼지의 원형 확산은 시각 효과이며 추가 피해를 중복시키지 않는다.

접촉 피해는 모든 살아 있는 적의 콜라이더 반지름과 월드 스케일을 반영한다. 플레이어/적의 상대 이동 구간도 검사하여 빠른 돌진 접촉을 놓치지 않는다. 기본 피해는 Inspector의 enemyContactDamage=64, 공통 무적은 1초이며 0.25초마다 검정(알파 0.6)/원래색(알파 0.8)으로 교대한다. 머리 위 회색 피해 텍스트는 떠오르면서도 회색을 유지한다. 일시정지에서는 타이머가 진행되지 않는다. 스탯/갑옷/유물의 최대 체력과 초당 회복을 사용하고 피해를 입었을 때 플레이어 HP바를 표시한다. 체력이 소진되면 같은 스테이지 중앙에서 체력을 회복하고 1초 보호를 이어간다. 재화나 스테이지는 차감하지 않는다.

적은 8유닛 안에서 0.35초 준비 후 시전 시점 플레이어 방향으로 0.3초/초당 8유닛 돌진한다. 최초 대기와 4~6.2초 쿨타임을 개체마다 어긋나게 둔다. 돌진 중 0.06초마다 0.22초 지속하는 반투명 잔상을 남기고 원본 스프라이트/크기/좌우 반전을 유지한다. 일반몹 3종과 보스에 동일하게 적용되며 접촉 피해는 공통 무적을 따른다.

도메인 리로드가 꺼진 설정(m_EnterPlayModeOptionsEnabled=1, Options=1)은 유지한다. UiKit/Collection/Variant/Expansion 이미지 정적 캐시는 SubsystemRegistration에서 지워지고, 조회 시 파괴된 Unity 스프라이트 또는 텍스처를 발견하면 즉시 재생성한다. 두 차례 캐시 파괴/재시작 훅 후 모든 스킬/동료 아이콘을 재조회하는 서버 검사를 추가했다.

출석은 수령 가능한 카드에만 클릭을 연결하고 순서/중복 지급을 다시 검증한다. 장착 슬롯 중앙 회색 반투명 '장착중' 프레임은 모든 공통 아이템 슬롯에 적용한다. 토스트 두 종류는 클릭을 막지 않는 프레임 안에서 비확장 시간 기준 페이드/확대 등장 후 사라진다.

Odin 메뉴 **Doodle Idle → 게임 정보**에서 현재 스테이지, 재화, 체력, 발견 아이템 수를 본다. **게임 정보 초기화**는 DoodleUi 저장 키 13개를 지우고 실행 중인 게임을 재시작한다. 초기 재화/장착/카탈로그/진행도는 처음 실행할 때와 같은 경로로 로드한다. 게임과 무관한 PlayerPrefs는 보존한다. 버튼을 구현했으며 사용자 저장 데이터에 실제 초기화를 실행하지 않았다.

검증은 GitHub Actions PlayMode에서 수행하며 탄환 비교 3장, 골렘 먼지, 접촉 무적 두 색, 번개 두 컷, 메테오, 스킬 5열 화면을 출력한다.
