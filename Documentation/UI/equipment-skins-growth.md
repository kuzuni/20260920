# 장비·성장·뽑기·스킨 확장

- 일반 스테이지의 기존 100마리 목표는 50마리로 변경. 돌파 ON 1~99스테이지는 20마리, 100스테이지부터 50마리.
- 목걸이 36종 추가. 같은 등급·번호·강화의 갑옷이 더하는 체력의 5%를 초당 기본 회복량에 더하고 회복 보유 배율 적용.
- 갑옷과 목걸이의 골드 보유 효과는 제거. 갑옷은 체력, 목걸이는 체력 회복 효과를 유지.
- 치명 확률 2→4→8→16→32→64→128배. 이전 단계를 만렙으로 만들어야 다음 단계 강화 가능. 다음 단계 첫 가격은 이전 단계 마지막 강화 가격, 이후 증가율은 2배 치명 확률의 마지막 증가율. 성공한 치명 중 가장 높은 단계만 적용.
- 뽑기 결과 상단에서 해당 뽑기권과 다이아 잔액 표시. 다이아 수량과 비용은 쉼표가 있는 원래 정수로 표시.
- 결과 하단에 연출 스킵은 왼쪽, ×1/×10/×100/×1000은 오른쪽. 유료 10회/50회 버튼의 횟수와 가격을 함께 배율 적용. 무료 5회는 별도 유지.
- 결과는 같은 항목을 합쳐 이번 뽑기에서 얻은 수량을 ×N으로 표시. 등급과 번호도 표시. 대량 뽑기는 매 1회마다 당시 뽑기 레벨 확률로 추첨하고 레벨 상승 직후부터 새 확률 사용.
- 외형 20종과 무기 20종, 기본 스킨 각 1종 별도. 100~2,000스테이지 클리어 기록으로 순서대로 해금 가능하며, 해금 버튼을 눌러야 획득.
- 외형 스킨 한 종류 보유당 골드 +50%, 무기 스킨 한 종류 보유당 공격력 +50%. 같은 분류의 보유 효과는 합산, 장비·스킬·동료·유물·스킨 분류 사이에는 곱셈. 장착 스킨을 바꿔도 보유 효과 유지.
- 기존 스킨 ID는 첫 다섯 테마에 유지하여 기존 보유/장착 저장 데이터를 이어받음.
- 코스튬은 기본 먼지고양이 원본 두 컷 위에 의상만 겹침. 얼굴·몸·팔다리와 원점/몸 크기를 그대로 유지하며 큰 모자는 몸을 축소하지 않고 위로 확장. 선택 미리보기 역시 두 컷과 공통 몸 크기 사용.
- 건담 테마는 최종 요청에 따라 분홍돼지/돼지코 망치로 교체. 얼음·불꽃 지팡이는 떨어진 조각 없이 한 덩어리 실루엣.

## 목걸이 그림체 통일 및 에디터 메모리 오류 조사 (2026-09-25)

- 줄, 구슬, 펜던트 및 부속 장식이 한 물체로 이어지도록 수정. 각각의 연결된 알파 픽셀 비율 99.5% 초과 및 투명 외곽 검사 추가. PNG 원본을 그대로 복사하고 JSON 스프라이트 범위만 다시 기록.
- 내장 이미지 생성 도구 사용. [최종 프롬프트 기록](necklace-style-prompts.json). 최종 파일: `Assets/DoodleIdle/Resources/DoodleIdle/UI/EquipmentNecklace.png`.
- 첨부된 오류는 저장 공간 부족이 아닌 메모리 할당 실패. `Editor-prev.log`에서 1,560,359,378바이트 요청이 `GUIStyle.DrawContent → EditorGUILayout.TextField → Odin StringDrawer → DoodleSkillTestWindow.SkillRow` 표시 경로에서 실패한 것을 확인. 검사 당시 C 드라이브 약 153GiB 및 물리 메모리 약 34GiB 여유. 당시 메모리 상태나 최초 손상 원인을 확정한 것은 아님.
- 스킬 테스트 창의 Odin 속성 트리를 기본 EditorWindow로 교체. 캐시한 길이 제한 이름과 썸네일을 사용하고 보이는 행만 그림. 반복 새로고침/스크롤/리페인트, 긴 이름과 잘못된 등급, 기존 발동 및 기본 공격 버튼을 회귀 검증. 기존 메모리 오류 자체를 재현한 검증은 아님.

## 원본 플레이어 기반 의상 및 보상 흡수 효과 수정

- `DoodlePlayerCostumeArt`가 원본 `Characters`의 플레이어 컷과 `PlayerWalkB`에 의상 전용 투명 레이어를 합성. `PlayerCostumeRig.json`의 눈 위치 기준으로 옷을 배치하며 모자·망토의 전체 범위로 몸을 정규화하지 않음.
- 전투에서 스킨을 별도 최대 크기로 다시 정규화하던 경로 제거. 기본 플레이어와 같은 이동 시계, 6회/초 프레임 전환, 정지 시 0번 컷, 흔들림/기울기를 사용.
- 스킨 목록 및 선택 미리보기에 공통 몸 크기를 사용하는 그래픽 적용. 선택 미리보기에는 두 컷 애니메이션 표시. [내장 이미지 생성 프롬프트와 원본](costume-overlay-prompts.json).
- 갑옷/목걸이 72종의 추가 골드 보유 값 제거. 과거 값이 남아 있어도 계산과 장비 설명에 반영되지 않도록 차단.
- 보상 팝업을 닫을 때 모든 뽑기권을 포함하여 흡수 효과 발생. 표시 중인 해당 뽑기권 잔액 또는 상점 버튼으로 이동. 골드·다이아·뽑기권 모두 입자 8개, 기본 크기 108 및 동일한 축소 곡선을 사용. 보상 지급과 연출을 분리하여 재지급 없음.

## 동료 만렙, 스킬·동료 합성, 레벨 표시

- 모든 동료의 최대 레벨은 스킬과 같은 100. 개별/일괄 강화와 상세 버튼에서 같은 제한을 사용. 기존 100 초과 저장은 100으로 정리하고 초과 구간에 사용한 강화 조각을 돌려주며, 다시 불러올 때 중복 반환하지 않음.
- 스킬·동료는 장비와 동일하게 100레벨에서 남은 조각 5개를 다음 순서의 항목 1개로 합성. 같은 등급의 다음 번호부터 이어지며, 등급 마지막 번호에서는 다음 등급 첫 번호로 이동. 최종 항목은 합성 불가. 원본의 레벨과 장착 상태는 유지.
- 개별 상세 화면 및 목록 하단의 일괄 합성 지원. 일괄 합성 중 이미 100레벨인 다음 항목에 조각 5개가 쌓이면 연속 합성. 기존 스킬 다이아 환불 버튼도 별도로 유지.
- 유물, 스탯, 장비 목록, 강화 알림, 뽑기 상세의 레벨은 `1,000`, `10,000`처럼 전체 숫자로 표시. 유물 레벨 배지 폭도 숫자 길이에 맞게 확장.
- 일반 유물과 던전 유물 최대 레벨을 1,000에서 **100,000,000**으로 상향. 50% 성공 확률, 실패 시 단계 유지 및 유물 1개 소모 규칙 유지. 만렙 표시·개별/일괄 강화·저장 복원에서 같은 상한 적용.
- 스킬·동료 화면에 해당 분류의 모든 항목이 100레벨일 때만 일괄 환불 버튼 표시. 남은 조각을 해당 분류의 현재 뽑기 1회 가격으로 환불. 지갑 공간만큼만 환불하고 지급하지 못한 조각은 보존. 원본 레벨·발견·장착 상태 유지.
- 장비 100레벨 초과는 갓 1만 허용. 근원 1도 100레벨 제한 및 과거 초과 강화 조각 1회 반환 적용.
- 강화 조각 소모량은 최대 20개. 갓 1 고레벨에서도 표시와 실제 소모량 모두 20개를 넘지 않음. 과거 근원 1 초과 강화 반환은 당시 지불한 상한 없는 비용을 기준으로 계산.
- 만렙에 도달하여 합성만 가능한 슬롯은 수량 게이지를 보라색으로 표시. 계속 강화할 수 있는 갓 1 등은 초록색 유지.
- 장비 총 보유효과는 선택한 탭만 집계·표시: 몽둥이 공격력, 갑옷 체력, 목걸이 체력 회복. 골드 항목은 표시하지 않음.

## 신의 손 착지 폭발

- 손바닥 전용 착지 분기에서 빠져 있던 폭발 파티클 호출 복구. 메테오와 동일한 충돌 처리 시점에 중심 폭발 1개, 바깥으로 퍼지는 폭발 조각 20개, 지면 먼지 16개 방출.
- 기존 폭발 그림을 하늘색 팔레트로 사용하여 손바닥 잔상과 연결. 손의 넓은 공격 범위에 맞춰 중심 폭발 크기 6.2 적용. 손 모양 지면 자국과 기존 범위 피해는 유지.
- 재사용 파티클 시스템으로 등록하여 일시정지, 재시작 및 정리 동작은 메테오와 동일하게 처리.

## 일괄 처리 및 던전 유물 아이콘

- 일괄 강화의 64회마다 저장·화면 재생성 제거. 장비·스킬·동료는 동일 비용 구간을 한 번에 계산하며, 갓 장비의 20개 고정 비용 구간은 나눗셈 한 번으로 처리.
- 유물은 기존 난수 순서 및 50% 확률을 유지하면서 숫자 계산만 묶어서 처리. 약 4ms 계산 단위로 실행권을 넘겨 화면 응답을 유지하고, 최종 저장·화면 갱신은 완료 후 한 번 수행. 퀘스트와 미션 횟수도 정확한 합계로 기록.
- 일괄 합성에서 항목마다 전투력 재계산·저장하던 경로 제거. 등급 순서대로 연속 합성한 후 한 번 저장·알림.
