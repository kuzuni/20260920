# 첫날 성장 기준

목표는 무료 보상을 모두 받고 스탯·장비·스킬·동료·유물·던전을 이용하는 8시간 플레이에서 약 300스테이지, 주요 스탯 Lv.1200, x2 치명타 약 30%, 공격력 약 1c다. 실제 도달 시간은 장착 조합, 뽑기 결과, 조작과 강화 시점에 따라 달라지며 아래 수치는 밸런스 기준이다.

## 성장과 수급

- 스탯 가격 증가율 1.004. 공격력/체력/회복/x2 치명타의 시작 가격은 20/18/16/20골드. 네 스탯을 각각 0→1200으로 올리는 합계는 약 221만 골드다.
- 공격력은 `(128 + 8 × Lv) × 1.0076^Lv`, 체력은 `(1280 + 80 × Lv) × 1.007^Lv`, 회복은 `(5 + Lv) × 1.007^Lv`다. 치명타는 레벨당 0.025%이며 Lv.4000에 100%다. 기존 저장의 x2 확률은 레벨을 4배 변환하여 유지한다.
- 몽둥이와 갑옷 장착 효과는 각각 스탯 공격력/체력에 대한 백분율이다. 일반1/고급1/희귀1/영웅1/전설1/신화1/갓1은 8/25/55/100/180/320/600%. 강화 레벨당 기본 효과의 15%가 추가된다.
- 적 처치 골드와 골드 동굴은 같은 `GoldForMainKills` 함수를 사용한다. 동굴 보상은 단계×50의 메인 스테이지 몬스터 500마리분이다.
- 초기 튜토리얼 20개 후 스탯 네 종류, 스테이지, 처치 수, 뽑기 다섯 종류의 11개 반복 주기를 사용한다. 던전 튜토리얼 2개는 스테이지45 주기 뒤에 한 번 삽입한다. 50스테이지 난이도의 던전이 초반 미션 수급을 막지 않도록 한 것이다. 미션당 50다이아+500골드이며 뽑기 미션은 다음 뽑기에 사용할 티켓을 공급한다. 한 번만 수행하는 행동은 영구 기록으로 확인한다.
- 미션 등장 전에 끝낸 행동도 인정한다. 기존 세이브는 출석 기록, 장비/유물 강화 단계, 던전 단계, 버프 사용 기록 등 남아 있는 증거를 가져온다. 구형 세이브에 전혀 기록되지 않은 과거 실패 시도까지 복원할 수는 없다.
- 무료 다이아는 하루 30회, 회당 균등 정수 200~1000개이며 합계 기대값은 18,000개다. 일일 경계는 기존 서비스와 같은 UTC다.

## 전투

- 적 체력은 해당 스테이지까지의 처치·미션 골드로 가능한 스탯 레벨을 추정한 뒤 장비·보유 효과·버프를 포함한 기준 공격력의 20.75배를 사용한다. 첫 50스테이지는 점진적으로 적용한다. 실제 플레이어의 현재 장비를 읽어서 적을 강하게 만드는 방식은 아니므로 추가 파밍과 좋은 장비의 이점은 유지된다.
- 적 접촉 피해는 같은 예상 스탯 레벨의 체력과 갑옷 성장에 맞추고 기준 체력의 0.45%를 사용한다(최소 기본 피해 64). 실제 회복량과 1초 피격 무적을 포함한 생존 여부는 서버 전투 테스트에서 검사한다.
- 스킬별 계수는 카탈로그 `damageMultiplier`에 있으며 스킬 Lv.1 이후 레벨당 2.5%가 추가된다. 범위 타격, 지속 피해, 추가 타격도 원래 스킬의 계수를 사용한다. 상세 1타 피해와 예상 DPS도 동일한 함수를 사용한다.
- 동료는 투사체 수와 공격 주기를 고려하여 일반~신화의 기본 이론 DPS를 플레이어 공격력의 22/40/58/76/94/112%/초로 맞춘다. 강화당 3%, 유물의 동료 공격력, 치명타가 추가로 적용된다. 범위에 여러 적이 맞으면 총 피해가 더 커진다.
- 사망 시 현재 메인 스테이지에서 한 단계 내려가고 처치 진행은 초기화한다. 최고 스테이지 기록과 이미 열린 스킬 슬롯은 유지한다. 던전 패배는 던전 종료로 처리한다.

## 뽑기와 상점

- `UiCommerce.json`은 요청받은 Lv.1~35의 35개 확률 행을 0.001% 단위 정수로 보관한다. 각 행의 합계는 100,000이다. 스킬/동료에는 갓이 없으므로 그 가중치를 신화에 더한다.
- 다음 레벨 필요 경험치는 50/100/200/400/800/1600/3200/6400/10000, 이후 10000이다. 뽑기 한 번당 경험치 1이다. 유물과 던전 유물은 레벨 없이 균등 확률이다.
- 같은 등급의 1~5번 비중은 60/25/10/4/1, 동료 1~4번은 64/25/9/2다. 515회 개별 뽑기를 기준으로 영웅1의 기대 획득량은 약 3.3개다. 10/50회 묶음은 실행 시작 레벨의 확률을 사용하므로 정확한 기대값은 묶음 방식에 따라 약간 달라진다. 확정 보장은 아니다.
- 마일리지 5개→150만, 10개→500만 다이아. 55,000원 상품은 쿠폰 1개, 110,000원 상품은 2개를 지급한다.
- 결제 서비스는 아직 연결되지 않았다. 상품 버튼은 결제를 실행하지 않으며 `GrantConfirmedCurrencyProduct`는 추후 영수증 검증 어댑터용 지급 진입점이다. 같은 거래 ID의 재지급은 거부한다.
- 마일리지의 최종 그림은 홈/절취선 없는 파란 다이아 카드다. `MILEAGE_DIAMOND_CARD.md`에 내장 image_gen 프롬프트를 기록했다.

## 검증

연속 측정은 `CONTINUOUS_CAMPAIGN.md`의 규칙을 사용한다. 새 계정에서 실제 보상·구매·강화·장착·던전·전투를 이어서 실행하고 `campaign.csv`에 구간별 시간을 기록한다. 사람의 메뉴 판단 지연은 재현하지 않으므로 자동 전투를 켜고 30초마다 관리하는 플레이 기준이다.

### 조정 과정

초기 시간 추정은 구간별 전투 효율을 모든 스테이지에 동일하게 적용했으며, 실제 도달 시간의 근거로 사용하지 않는다. 물리 시간 통일 전의 연속 측정 `35788138570`은 5시간 3분 57초, 메인 스테이지 강등 13회, 스탯 약 Lv.1257, 공격력 약 4.60c였다. 이 기록에는 배속에 따른 기본 공격 범위 오차가 포함되어 잠정 자료로만 보관한다. 해당 원본은 `BalanceRuns/eight-hour-baseline.csv`다.

현재 코드는 기본 공격 탄환과 돌의 피해 판정, 전투 경과 시간을 물리 틱으로 통일했다. 이전 렌더 프레임 기반 이동에서는 긴 프레임의 이동량이 탄환 수명을 초과하여 공격 범위가 달라질 수 있었다. `BasicShotDamageAndRangeIgnoreExtraRenderUpdates`는 물리 틱 사이에 렌더 업데이트를 30회 추가해도 탄환 수명·위치·피해가 변하지 않고, 이후 실제 물리 틱에서는 명중·만료되는 것을 검사한다.

물리 시간 통일 후 적 체력 계수 10의 연속 측정 `35790120542`는 300 클리어까지 4시간 36분 11초, 네 스탯 Lv.1235, 공격력 약 1.25c, 메인 스테이지 강등 1회였다. 골드·유물 동굴은 각각 3단계까지 클리어했다. 원본은 `BalanceRuns/fixed-clock-ratio10.csv`다. 이 실행의 전체 109개 검사 중 108개가 통과했으며, 나머지는 장시간 경과 후 테스트의 `float` 시간 기록이 공격 간격을 반올림하는 문제였다. 해당 기록을 `Time.fixedTimeAsDouble`로 바꾸고 기존 간격 허용치는 그대로 유지했다.

[계수 18의 측정 35793323471](https://github.com/kuzuni/20260920/actions/runs/35793323471)은 연속 성장·새 렌더 독립성 검사·기존 공격 간격 검사·구간 전투·표시 피해량 검사 5개가 모두 통과했다. 300 클리어는 7시간 8분 5초, 스탯 Lv.1234~1235, 공격력 1.26c, 메인 스테이지 강등 1회였다. 원본은 `BalanceRuns/fixed-clock-ratio18.csv`다. 시간 목표와의 차이를 줄이기 위해 체력 계수를 20.75로 조정한다.

보상·거래 중복 방지·영구 기록·강등·뽑기 확률·세이브 변환·실제 피해량·구간 전투는 `day-one` 범위에 포함된다. 전체 회귀 결과와 이후 체력 계수 조정의 집중 검사 결과는 위 기록처럼 구분한다. Unity 실행과 검사는 모두 GitHub Actions에서만 수행한다.
