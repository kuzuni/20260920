## 장비·등급·확률

- 갑옷과 몽둥이에 각각 근원 가시, 근원 수정, 초월 날개, 초월 별빛, 갓 태양 5개씩 추가한다.
- 기존 갓 장비 ID와 수치, 저장된 보유량·강화 레벨·장착 상태는 유지하고 표시 등급을 근원으로 변경한다. 기존 무제한 강화도 유지한다.
- 등급 인덱스 6=근원, 7=초월, 8=갓. 합성은 실제 카탈로그의 다음 장비로 이어진다.
- 뽑기 최대 레벨은 50. 1~34레벨의 기존 확률을 유지한다. 스킬·동료는 35레벨부터 근원을 뽑을 수 있고, 장비의 기존 근원(구 갓) 해금은 유지한다. 초월은 35레벨, 갓은 45레벨부터 등장한다.
- 50레벨 확률: 일반 15%, 고급 20%, 희귀 20%, 영웅 20%, 전설 18%, 신화 1.9%, 근원 3%, 초월 2%, 갓 0.1%.
- 동일 등급 내 가중치는 기존 10:9:8:7:6 패턴을 해당 등급의 실제 아이템 개수에 맞춰 정규화한다. 유물은 기존 균등 확률을 유지한다.

- 생성 프롬프트 및 최종 PNG 경로: [스킬·장비](ascension-art-prompts.json), [동료·투척물](ascension-companion-art-prompts.json).
- 검증은 GitHub Actions의 Unity PlayMode에서 수행한다. `ascension` 수동 실행 옵션은 신규 전투, 저장 이관, 카탈로그, 장비 합성, 확률, 피해량과 아트 검사를 포함한다.
- 실제 uGUI/URP 렌더 결과는 CI 아티팩트의 `ascension-*.png`, 검사 결과는 `playmode-results.xml`에 저장한다.
