# 근원·초월 확장과 보스전

기존 플레이어와 같은 굵은 검정 외곽선과 단순한 낙서 그림체를 사용한다. 스킬과 동료는 갓 등급을 제거하고 근원·초월까지만 구성한다. 장비의 갓 등급은 유지한다.

## 스킬

근원 5개, 초월 5개. 모든 신규 스킬은 기존 스킬처럼 공격의 특징을 보여주는 전용 썸네일을 사용한다.

## 동료

근원 4개: 황금톱니바퀴(작은 톱니), 빗살무늬토기(토기 조각), 청동검(작은 청동검), 전갈(독방울 5개 분사).

초월 4개: 불나방(불씨), boat(구명튜브), GOAT(클로버), 태양(작은 태양). 키메라와 지구는 카탈로그에서 제거한다.

두 컷은 동일한 팔다리 수를 유지한다. GOAT는 두 컷 모두 발굽 2개. 청동검은 손 2·발 2, 태양은 손 2·발 0을 유지한다. [이전 팔다리 수정 기록](ascension-anatomy-edit-prompts.json).

## 장비·확률

- 기존 갓 장비는 ID·보유량·강화·장착을 유지한 채 근원으로 표시한다. 신규 장비는 갑옷과 몽둥이 각각 5개다.
- 뽑기 최대 레벨 50. 1~34레벨의 기존 확률을 유지하고 35레벨부터 새 등급 확률을 적용한다.
- 50레벨: 일반 15%, 고급 20%, 희귀 20%, 영웅 20%, 전설 18%, 신화 1.9%, 근원 3%.
- 장비는 초월 2%·갓 0.1%, 스킬·동료는 초월 2.1%이며 갓 확률과 표시 행이 없다.
- 동일 등급 내 기존 가중치 패턴(10:9:8:7:6)을 실제 개수에 맞춘다. 유물은 기존 균등 확률을 유지한다.

## 스테이지와 보스

- 돌파 ON: 표시 스테이지 1~99는 20마리, 100~299는 50마리, 300부터 100마리 처치 후 보스 등장.
- 보스 제한 시간 10초. 스테이지 텍스트 아래·돌파 버튼 위에 체력바와 파란 타이머바를 함께 표시한다. 일시정지 중 타이머도 멈춘다.
- 시간 초과 또는 보스전 사망 시 같은 스테이지에서 처치 수 0부터 재시작하고 돌파 ON을 유지한다. 일반 사망도 스테이지나 처치 수가 내려가지 않는다.
- 일반 몬스터는 대시하지 않는다. 보스는 표시 100스테이지부터 대시하며 속도 8, 지속 시간 0.9초로 기존 이동 거리의 3배다.
- 돌파 OFF의 일반 파밍 주기는 100마리를 유지한다.

일반 안내와 전투력 변화 토스트는 화면 높이 70% 부근에 표시하며 서로 86 단위 간격을 둔다.

## 밸런스 자동 저장

플레이 중 밸런스 창의 시작값·증가율·구간·강화 비용·유지 거리를 바꾸면 즉시 적용하고 `ServicesTuning.json`과 `Collections.json`에 저장한다. 실행 중 적용 버튼도 저장을 포함한다. 변경 없는 다시 그리기는 파일을 쓰지 않으며 실행 취소·다시 실행도 자동 저장한다. 편집 모드에서는 저장 버튼을 사용한다.

공격력 버프와 골드 버프는 각각 +100%(활성 중 배율 2배)이며 화면 설명도 같은 값을 표시한다.

보상 카드 뒤에는 반투명 금빛 방사형 줄무늬 12개가 시계 방향으로 초당 18도 회전한다. 보상 창이 열리면 실제 ParticleSystem에서 양쪽 축하 색종이를 발사하고 uGUI로 렌더한다. 색종이 크기는 18~32로 기존의 2배이며 발사 범위도 넓혔다. 게임 일시정지에도 재생되며 팝업 종료 시 함께 제거된다.
