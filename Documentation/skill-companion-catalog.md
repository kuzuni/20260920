# 스킬·동료 목록

스킬은 일반~신화 등급당 5종(총 30종), 동료는 등급당 4종(총 24종)이다. 기존 ID로 보유 조각·레벨을 이어받으며 갓은 장비에만 존재한다. 스킬은 장착한 경우에만 자동 발동한다. Odin 테스트 버튼으로는 미장착 스킬도 시험 발동할 수 있다.
