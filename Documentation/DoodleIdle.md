# 낙서 원정대 · Unity 2D 방치형 프로토타입

Unity 6000.3.8f1 프로젝트입니다. `Assets/DoodleIdle/DoodleIdle.unity`를 열고 Play를 누르면 자동 전투가 시작됩니다. 씬이 아직 없다면 **Doodle Idle → Create or Open Prototype** 메뉴로 생성합니다.

## 구현 범위

- 머리와 떠 있는 방망이만 있는 플레이어. 직접 생성한 참조 그림체의 스프라이트 사용.
- 직접 생성한 베이지색 흙바닥. 위에서 내려다보는 바닥만 표시하며, 인접 타일을 반전하여 경계가 이어집니다.
- 머리+다리 버섯, 머리+날개 박쥐, 머리+뿔+날개 악마의 적 3종, 시작 200마리. 20마리 미만이 되는 즉시 살아 있는 적을 포함해 200마리까지 보충.
- 플레이어와 적: 중력 없는 Dynamic Rigidbody2D + CircleCollider2D. 적끼리 겹치지 않게 초기 위치 검사 및 물리 충돌. 바위에는 고정 콜라이더, 지도 가장자리에는 보이지 않는 경계 콜라이더 적용.
- 가까운 적을 향해 자동 이동, 0.65초마다 방망이를 휘둘러 전방 검기를 발사.
- 5초마다 가급적 4~9유닛 떨어진 적에게 대시. 이동 경로를 쓸어 검사하여 적을 타격하고 잔상 생성.
- 바나나 5개가 항상 플레이어 주위를 공전. 적별 0.35초 재피격 간격.
- 3.2초마다 가장 가까운 서로 다른 적 최대 3명에게 돌멩이를 하나씩 포물선으로 발사.
- 바나나 크기는 최초 버전의 2배, 투척 돌은 3배, 피격 파편은 4배입니다.
- 화살: 4.5초마다 가까운 적들을 향해 0.1초 간격으로 10발 연사.
- 탱탱볼: 7초마다 발사. 적 사이에서만 튕기며 같은 적을 연속으로 맞히지 않고, 7번째 적 충돌 후 소멸. 지형/플레이어와 충돌하지 않습니다.
- 불꽃: 5.5초마다 가까운 서로 다른 적 3명에게 발사. 주황색 불꽃 잔상을 남깁니다.
- 드론: 플레이어 옆을 따라다니며 6초마다 가까운 적들에게 0.06초 간격으로 포물선 미사일 20발 발사.
- 지렁이: 8초마다 플레이어 위치에서 출발해 바깥으로 나선을 그립니다. 머리와 원형 몸통 12개가 순서대로 나타나 머리의 경로를 따라가며, 6.5초 후 사라집니다.
- 백그라운드 실행: Player Settings와 런타임의 Run In Background를 모두 켰습니다. 창의 포커스를 잃어도 전투가 계속됩니다.
- 탱탱볼에는 0.04초 간격의 흐려지는 잔상이 붙습니다.
- 5방향 뱀: 7초마다 다섯 방향으로 물결을 그리며 전진하고, 몸통이 순서대로 따라오면서 주변 적을 타격합니다.
- 샷건: 4.5초마다 가까운 적 방향으로 산탄 20발을 부채꼴로 동시에 발사합니다.
- 수호검: 플레이어 오른쪽을 따라다니며 검 기준 5유닛 안의 적에게 0.7초마다 관통 검기를 발사합니다.
- 설치 대포: 14초마다 현재 플레이어 위치에 설치되고 10초 동안 고정됩니다. 9유닛 이내 적에게 0.85초마다 포물선 포탄을 쏘며, 착탄 지점 반경 2.2유닛에 폭발 피해를 줍니다.
- 오이: 6초마다 가까운 적 방향으로 직진하며 옆으로 굴러가는 회전/눌림 동작을 보여줍니다. 스친 모든 적을 각각 한 번 타격합니다.
- 추적 뱀: 보라색 머리와 몸통을 플레이어보다 아래에 표시하며, 9초마다 6초간 유지됩니다. 꼬리가 플레이어에 붙어 있고, 머리가 7유닛 안의 적을 추적하며 0.18초 간격으로 다단히트합니다. 적이 죽으면 근처 표적으로 전환합니다.
- 번개 구름: 생성 이미지 2컷을 초당 4컷으로 교체하며, 10초마다 소환되어 8초간 초당 0.65유닛으로 이동합니다. 0.7초마다 주변 적 최대 3명에게 번개를 쏘고 잔상을 남깁니다.
- 원형 불꽃: 7초마다 24개의 불꽃이 원형으로 퍼지며 접촉한 적을 관통 타격하고 잔상을 남깁니다.
- 모래 뿌리기: 5초마다 가까운 적 3명 방향으로 퍼지는 모래를 발사합니다. 잔상과 0.22초 재피격 간격이 있습니다.
- 화염 드래곤: 11초마다 소환되어 6초간 물결 경로로 이동합니다. 몸통의 순차 등장, 위/아래 날개 2컷 애니메이션, 입에서 3방향으로 흩뿌리는 불꽃을 사용합니다.
- 빨간 검기 5연발: 9초마다 0.48초 간격으로 5발을 발사합니다. 일반 검기와 같은 초당 11유닛 속도, 12.1유닛 사거리, 4.2유닛 크기와 2.1유닛 접촉 반경을 사용합니다. 곡선 칼날이 이동 방향을 향하고 생성한 2컷과 잔상을 표시하며, 각 발이 적마다 한 번씩 피해를 줍니다.
- 적 사망 위치에 찌그러뜨리지 않은 원형 비율의 투명도 28% 검정 자국을 남깁니다. 4초 유지 후 2초간 사라지며, 최대 180개로 제한합니다. 플레이어와 적 모두 지면 그림자가 있습니다.
- 하단 HUD에는 총 23개 스킬과 재사용 시간이 표시됩니다.
- 피격 틴트, 먼지, 대시 잔상, 처치/생존/보충 횟수 및 쿨다운 표시.

전투와 충돌을 검증하기 위한 최소 샌드박스이며, 플레이어 사망/성장/저장/상점은 포함하지 않습니다. 기본적으로 자동 전투가 계속됩니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| Space / 일시정지 버튼 | 일시정지 또는 계속 |
| R / 다시 시작 버튼 | 적 200마리와 초기 스킬 상태로 재시작 |
| Tab | 자동/수동 이동 전환 |
| WASD / 방향키 | 수동 모드에서 이동; 공격과 스킬은 계속 자동 |

`Doodle Idle Prototype` 오브젝트의 `DoodleIdleGame` Inspector에서 적 수, 보충 임계값, 맵 크기, 이동 속도, 스킬 간격을 조정할 수 있습니다.

플레이 모드 진입 옵션은 **도메인 리로드 끄기 / 씬 리로드 켜기**로 설정했습니다. 플레이 진입마다 .NET 도메인을 다시 구성하는 시간을 줄이며, 씬을 다시 로드해서 전투 상태는 새로 시작합니다. 런타임 전투 상태는 static 필드에 저장하지 않습니다.

## 검증 및 빌드

- **GitHub Actions → Doodle Idle Unity tests**: 서버의 PlayMode 테스트가 실제 물리 충돌 및 120초 자동 전투를 검사합니다. 결과 XML과 Unity 로그는 Actions 아티팩트로 저장합니다. 설정은 `Documentation/CI.md` 참조.
- **Doodle Idle → Build Windows Prototype**: `Builds/DoodleIdle/DoodleIdle.exe` 생성.

## 전투 연출 업데이트

- 필드: 34 × 40유닛으로 세로 확장. 기존 20마리 미만 보충 기준은 유지합니다.
- 대포 폭발, 피격/착탄 먼지, 모래 잔상은 Unity ParticleSystem을 사용합니다. 다섯 개의 재사용 시스템으로 관리하며 전투 일시정지/재시작에 맞춰 멈추고 정리합니다.
- 적 사망 위치에서 직접 생성한 금화 9개가 회전하며 퍼졌다가 0.4~0.625초 후 사라집니다. 획득/재화 저장 기능은 없습니다.
- 적 머리 위에 직접 생성한 낙서풍 HP 프레임/녹색 채움이 표시됩니다. 피해 숫자는 게임과 동일한 손글씨 폰트로 떠오르며 0.75초 후 사라집니다. 숫자는 최대 128개를 재사용합니다.
- 추가 생성 에셋과 정확한 프롬프트: [particle-revision-image-prompts.md](particle-revision-image-prompts.md).

- 대포 포구: 생성 이미지의 포구 중앙에 자식 발사점을 두고 좌우 반전과 반동 변형을 따라가게 했습니다. 포탄은 이 발사점에서 출발합니다. 발사마다 DOTween PunchScale/PunchRotation으로 0.42초간 눌림/기울기/탄성 복귀를 연출하며, 일시정지·철거·리셋 때 함께 정지하거나 정리합니다.

- 플레이어와 적은 이동 시 초당 6컷의 2프레임 애니메이션을 사용합니다. 플레이어의 첫 프레임은 기존 아틀라스 디자인 그대로이며, 두 번째 프레임은 같은 디자인의 미세한 눌림 포즈입니다. 적은 버섯의 좌우 발걸음, 박쥐/악마의 날개 위아래 프레임을 교체합니다. 정지한 플레이어는 기존 첫 프레임으로 돌아옵니다.
- 이동용 생성 이미지와 프롬프트는 [actor-animation-image-prompts.md](actor-animation-image-prompts.md)에 기록했습니다.


- 데미지 숫자는 기존 대비 2배(84pt), 오이는 크기/접촉 범위 2배입니다. 금화는 분출 속도 2배, 수명 절반으로 빠르게 터집니다.
- 고양이 로봇 드론은 플레이어와 같은 낙서풍의 새 2컷(8fps) 디자인입니다. 본체에 미사일은 그려져 있지 않으며, 미사일 20발 공격 기능은 유지합니다.
- 방망이는 손잡이 내부 피벗으로 회전하고 고양이 머리 옆 손 위치를 따라갑니다. 수호검도 손잡이 기준으로 0.34초간 크게 휘두릅니다.
- 화염병: 8초마다 가까운 적 위치로 0.8초간 포물선 투척. 착탄 폭발 후 반경 2.3유닛에 4초간 불 파티클 영역이 생기며, 0.35초마다 접촉한 적들에게 8 피해를 줍니다. 불 영역은 투척 시 정한 위치에 남습니다.
- 음파: 6초마다 가까운 적 방향을 정하고, 플레이어에서 0.18초 간격으로 도넛 고리 5개를 발사합니다. 각 고리는 초당 7유닛으로 1.5초간 전진하면서 지름 0.7→3.1유닛으로 커집니다. 고리마다 적당 24 피해를 한 번 주므로 여러 고리에 맞으면 연속 피해를 받습니다. 일시정지와 재시작 시 대기 중인 발사도 함께 멈추거나 초기화됩니다.
- 최종 드론/화염병/음파/불 파티클 이미지와 프롬프트: [robot-and-area-image-prompts.md](robot-and-area-image-prompts.md).

## 조작과 회전 연사총

- 게임 필드를 클릭/터치한 자리에서 조이스틱이 나타납니다. 드래그하는 동안 직접 이동하고, 손을 떼면 기존 자동 이동 설정으로 돌아갑니다. HUD 버튼 위에서는 시작하지 않습니다. 조작 중 자동 대시와 자동 장애물 우회는 이동 방향을 덮어쓰지 않습니다.
- `Application.targetFrameRate = 60`, `QualitySettings.vSyncCount = 0`으로 60fps를 목표로 합니다. 실제 유지 여부는 실행 기기의 성능에 따라 달라집니다.
- 바나나는 시작부터 8초 유지 후 4초 동안 사라지고, 12초 주기로 다시 나타납니다. 숨은 동안 콜라이더와 피해 판정도 비활성화됩니다.
- 회전 연사총은 8초 동안 플레이어 주변 반경 2.5유닛을 돌며, 10유닛 내 가까운 적 방향으로 0.09초마다 연사합니다. 4초 휴식 후 재소환됩니다. 총 본체에는 충돌 피해가 없습니다. 총알은 첫 접촉 적에게 8 피해를 주고 사라집니다.
- 총알은 실제 총구 자식 Transform에서 출발합니다. 발사마다 손그림 총구 불꽃과 DOTween PunchScale 반동을 표시합니다. 일시정지 때 총의 궤도/연사/반동이 정지하고, 수명 종료/리셋 때 트윈과 총 오브젝트를 정리합니다.
- 생성 이미지와 프롬프트: [orbit-gun-image-prompts.md](orbit-gun-image-prompts.md).
