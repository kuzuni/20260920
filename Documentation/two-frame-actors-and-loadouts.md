# 2026-09-21 complete two-frame actors, skill thumbnails and companion attacks

Method: built-in `image_gen` (no CLI/API fallback). Generated PNGs are copied without pixel edits into `Assets/DoodleIdle/Resources/DoodleIdle`. Python/Pillow is used only to inspect alpha bounds and write Unity slicing JSON; it does not rewrite image pixels. All Unity rendering/testing runs in GitHub Actions.

Latest accepted anatomy references: [two-foot mushroom](UI/MotionReferences/mushroom-two-feet.png), [sprout arms and feet](UI/MotionReferences/sprout-arms-feet.png), [pea arms and feet](UI/MotionReferences/pea-arms-feet.png). Walkers alternate their forward/back feet. Winged types alternate raised/lowered wings. Complete characters occupy both animation cells. Eye design and limb count stay consistent. No separated limb assets are used.

Enemy atlases: `Themes/{Meadow,Desert,Forest,Swamp,Volcano,Coast,Crystal,Twilight,Ruins,Glacier}.png`, 3 columns × 2 rows. Companion atlases: `CompanionMons{Normal,Advanced,Rare,Epic,Legendary,Mythic}.png`, 4 columns × 2 rows. The first row is A, second row B. Pairs share crop dimensions and pixels per unit; runtime animation selects 6 frames per second. Coast hermit source art faces left and is normalized via `facesLeft` before applying travel direction.

Skill thumbnails use six `SkillThumbs{grade}.png` 2×2 sheets. Projectile art uses `CompanionAttacks{A,B,C}.png` (4×2) plus `CompanionSpecialAttacks.png` (3×2). Stable catalog IDs retain saved ownership; icons and gameplay patterns are listed in `UI/Collections.json`.

Odin window: `Doodle Idle/스킬 발동 테스트`. Its 24 buttons are available during Play with a living target. Explicit tests bypass equipment/ownership without changing wallet or loadout. Normal automatic casting uses only currently equipped skills; unequipping cancels queued automatic shots.
